Karten-Editor

Daten eintragen, Vorschau prüfen, Datei erzeugen. Kein Code nötig.

1 · Wer ist auf der Karte?

Das Markenlogo steht im schwarzen Band über der Karte und ist auf jeder Karte gleich. Ein Porträt erscheint darunter.

2 · Kontaktdaten

Diese Angaben landen im Adressbuch, wenn jemand „Kontakt speichern" drückt. Leere Felder verschwinden von der Karte.

4 · Fußzeile
5 · Adresse der Karte

Ergibt k/…/ – diese Adresse kommt auf den NFC-Chip. Sie darf sich später nicht mehr ändern.

So kommt die Änderung online
  1. Datei herunterladen oder Text kopieren.
  2. Auf GitHub in den Ordner k/…/ gehen.
  3. profil.js öffnen → Stift-Symbol → alten Inhalt ersetzen.
  4. Commit changes drücken. Nach ein bis zwei Minuten ist die Karte aktuell.
